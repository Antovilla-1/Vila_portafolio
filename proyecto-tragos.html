COLECCIÓN DE CARTAS PARA BARISTAS

Set de 20 cartas con distintos tipos de tragos.
Este proyecto mezcla la cultura del trago con el folclore lingüístico chileno. Chile es un país en donde el compartir un copete es sinónimo de encuentro y amistad. Es por eso que estos set de cartas informan sobre bebidas icónicas del mundo y les añade el lenguaje cotidiano chilenos para darles humor, picardía y cercanía con el publico al que se dirigen.
El proyecto no busca informar sobre la cantidad de alcohol que posee cada bebida, ni que ingredientes tiene, sino que esta creado con la intención de hacer de estas bebidas una excusa para conversar, reírse y pasar un rato agradable.
